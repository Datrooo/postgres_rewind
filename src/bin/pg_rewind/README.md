# Forensic WAL Decode In `pg_rewind`

модуль декодирует участок WAL во время `pg_rewind` и сохраняет forensic-результаты в `/tmp/pg_rewind_wal`.

## Что нужно для работы

Собирать и устанавливать нужно в локальный `install/` в корне репозитория

После этого для запуска тестов:

```bash
cd src/bin/pg_rewind/forensic_scripts
source ./forensic_env.sh
./forensic_run_all.sh
```

## Примечание

Сейчас путь через `./install` обязателен для тестовых скриптов (`forensic_env.sh` ожидает `install/bin` и `install/lib`).
В будущем это можно сделать настраиваемым.
